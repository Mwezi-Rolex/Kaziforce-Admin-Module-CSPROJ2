## Phase 4 — Hardening

- **D-041** — Accessibility contrast fixed by measurement, not by eye. A script over `src/**/*.{tsx,css}` computed WCAG ratios for every text colour against every light surface; **31 tokens fell below 4.5:1** and were darkened to the nearest compliant value (hue preserved). The focus ring `#c99434` measured 2.48:1 and failed the 3:1 non-text rule, so it became `#ad7f2d` (≥3.03:1 on all surfaces, 3.45:1 on the dark panel). Scrollbar thumb `#718078` on track `#e6e5dc` = 3.28:1, which passes as a non-text control. These are the only deliberate deviations from the Figma palette, made for NFR-ACC-004. — 2026-10-30
- **D-042** — Responsive layout rebuilt around semantic hooks (`.console-rail`, `.console-main`, `.console-header`, `.console-content`, `.header-meta`) rather than Tailwind's escaped arbitrary-value selectors, because the latter are unreadable and fragile in media queries. Breakpoints: ≥1200 px rail 252 px; 900–1199 px rail 210 px with tighter gutters; <900 px rail 176 px and stacked panels. Verified present in the built CSS. — 2026-10-30
- **D-043** — `SEC-AUD-002` (log authorization decisions) implemented as an `Authorization Denied` audit event written from `requirePermission` before the 403 is returned. The write is best-effort and never blocks the denial, because failing open would be worse than a missing log entry. — 2026-10-30
- **D-044** — `ZodError` is now mapped to 422 with the first issue's message in the shared error handler. Previously a schema parse that escaped a route's own `safeParse` produced a 500, which both hid the cause and leaked an internal error shape (FR-ERR-002/004). Found by the settings malformed-key test. — 2026-10-30
- **D-045** — Jest must run with `--runInBand` (already the `npm test` script). Running the suites in parallel lets them share one database, and state-mutating suites then interfere; this was observed once as a single spurious failure and did not reproduce across six sequential runs. Recorded so the flakiness is not mistaken for a real defect. — 2026-10-30
