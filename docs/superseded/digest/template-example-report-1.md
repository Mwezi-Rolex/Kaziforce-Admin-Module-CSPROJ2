# Example Report 1 template digest

Source: `src/imports/ICS 410X CS Project II - Example Report 1.md` (about 2,300 lines). Format/structure reference only; defines no product requirements for this project.

## Structure used

1. Front matter: declaration/approval, acknowledgment, abstract, table of contents, lists of figures and tables, abbreviations.
2. Chapter 1: Introduction.
3. Chapter 2: Literature Review, including conceptual framework.
4. Chapter 3: Development Methodology, including tools/techniques and system deliverables.
5. Chapter 4: System Analysis and Design, with use case, class, sequence, activity, package, architecture diagrams and wireframes.
6. Chapter 5: System Implementation and Testing, including implementation environment, dataset/model evaluation, functional testing, results and GitHub documentation.
7. Chapter 6: Conclusions, Recommendations and Future Works.
8. References and appendices, including login/other screens and a Turnitin report.

## Patterns worth reusing

9. Figure numbering is chapter-scoped, for example Figure 4.1 for the use-case diagram and Figures 4.7–4.10 for wireframes.
10. Implementation evidence is presented with environment details, datasets, functional test tables, model/sample outputs and screenshots.
11. Appendices carry screen captures, repository evidence and originality evidence.
12. This is an AI/ML project example, so its dataset/model-evaluation subsections do not transfer directly; the chapter skeleton does.
13. No binding product requirements are established by this template.
