## Appendix 6: Environment variables

Recorded here because the system does not start without them, and because the
project rules require that no secret appears in the repository. Values are never
listed; only names and purposes.

| Variable | Required | Purpose |
|---|---|---|
| `DATABASE_URL` | yes | application-role connection (restricted grants) |
| `OWNER_DATABASE_URL` | for migrations and seeding | schema-owner connection |
| `JWT_SECRET` | yes | signs the session token (minimum 16 characters) |
| `PORT` | no | API port, default 3000 |
| `NODE_ENV` | no | `production` enables the secure cookie flag and the production seed guards |
| `TRUST_PROXY` | behind a reverse proxy | set to `1` so the rate limiter sees real client addresses |
| `RATE_LIMIT_MAX`, `RATE_LIMIT_WINDOW_MS` | no | defaults 600 and 300000 |
| `MODEL_SERVICE_URL` | no | default `http://127.0.0.1:8000` |
| `MODEL_TIMEOUT_MS` | no | default 800 ms; the queue never waits longer |
| `SEED_VIEWER_PASSWORD`, `SEED_MODERATOR_PASSWORD`, `SEED_SUPERADMIN_PASSWORD` | production seeding | required when `NODE_ENV=production`; the seed refuses demo passwords |

The environment file is gitignored, is generated at setup time by
`npm run bootstrap`, and is never committed or printed.
